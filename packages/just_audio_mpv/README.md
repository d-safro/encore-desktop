# just_audio_mpv

Encore's copy of [just_audio_media_kit](https://github.com/Pato05/just_audio_media_kit) 2.1.0 (public domain),
which plays just_audio's sources through libmpv on Linux. Changed for Encore: inserts in the middle of the queue,
sound filters (equalizer, pitch, skip silence, ReplayGain gain), an app volume, and the output device list.
